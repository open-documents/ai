用一个真正由 ODE 生成、且能全程算出来的最简单例子：一维缩放流 + 标准高斯。

1. 设定
流：取向量场 v_t(x) = x，解 ODE：


d/dt φ_t(x_0) = φ_t(x_0),   φ_0(x_0) = x_0
⇒ φ_t(x_0) = e^t · x_0
即：t 时刻把整条直线拉伸 e^t 倍。

初始密度：p_0 = N(0, 1)。

2. 逐项计算式 (4) 的四个部件
目标：求 t 时刻密度 p_t(x)。

部件	计算
① 目标点 x	任取一个数，如 x = 1
② 回溯源点 φ_t^{-1}(x)	ODE 反解：φ_t^{-1}(x) = e^{−t} x
③ 源点密度 p_0(φ_t^{-1}(x))	p_0(e^{−t} x) = (1/√(2π)) exp(−e^{−2t}x²/2)
④ 体积因子 det[∂φ_t^{-1}(x)/∂x]	一维时就是导数：e^{−t}
3. 代入式 (4)

p_t(x) = p_0(e^{−t}x) · e^{−t}
       = (1/√(2π)) exp(−e^{−2t}x²/2) · e^{−t}
       = (1/(√(2π)·e^t)) exp(−x²/(2e^{2t}))
       = N(x | 0, e^{2t})
结果：本来方差为 1 的高斯，被流拉伸后变成方差为 e^{2t} 的高斯。接下来做验证。

4. 数值验证（取 t = ln 2）
此时 e^t = 2，流就是 φ(x_0) = 2x_0，空间被拉伸 2 倍。

量	数值
目标点	x = 2
源点	φ^{-1}(2) = 1
p_0(1)	0.24197
det = 1/2	0.5
乘积	0.1210
直接算 N(0,4) 在 x=2 处的密度：


(1/(2√(2π))) exp(−2²/(2·4)) = 0.19947 × 0.60653 = 0.1210  ✓
再验证总质量仍为 1：


∫ p_t(x) dx = ∫ p_0(e^{−t}x)·e^{−t} dx
             = ∫ p_0(u) du        （令 u = e^{−t}x）
             = 1  ✓
这正是"变量替换 + 质量守恒"的含义：空间的长度被拉伸了 2 倍，密度就必须缩小到 1/2。高斯峰值从 N(0,1) 的 0.3989 降到 N(0,4) 的 0.1995，恰好减半。

5. 直觉对照

     t=0 源                                 t 时刻
   p_0 = N(0,1)                          p_t = N(0, e^{2t})
      ▁▄█▄▁                    ──►           ▁▄▄█▄▄▁   （变宽、变矮）
      x_0 ──── 流拉伸 e^t 倍 ────►  x = e^t x_0
要问 x 处的密度 → 先回溯到源点 e^{−t}x → 查 p_0 → 再乘体积因子 e^{−t}。
流把体积放大 e^t 倍 ⇒ 密度乘 e^{−t}；e^{−t} = 1/det(∂φ_t/∂x)，与上一问的"正、逆雅可比互为倒数"一致。
6. 换成矩阵版本
同样的事情在二维：若 φ(x_0) = A x_0，A = diag(2, 3)，则


det[∂φ^{-1}(x)/∂x] = det(A^{-1}) = 1/(2·3) = 1/6
p_0 = N(0, I) 时 p_t = N(0, AAᵀ) = 分布被拉伸成 2×3 的椭圆，密度处处乘以 1/6。若 A = diag(2, 1/2)，det = 1：一个方向拉宽、一个方向压窄，面积不变，密度不变——这就是前面说的"det 只管体积，不管形状"。

一句话
式 (4) 在这个例子里就是：N(0,1) 被拉伸 e^t 倍后，密度变成 N(0, e^{2t})；公式里的 p_0(e^{−t}x) 负责"查源点密度"，e^{−t} 负责"按体积变化打折"，两者相乘恰好给出正确的密度。



用一个更加简单的例子
2:16 AM
最简单的版本：把一条线段均匀拉长一倍。

设定
初始分布：X_0 在 [0, 1] 上均匀分布，密度是常数 1：


p_0(x) = 1,   0 ≤ x ≤ 1
       = 0,   其他
流：φ(x) = 2x（把线段拉伸到原来的 2 倍）。这不是用 ODE 解出来的，但任意一个可逆映射都能直接代入式 (4) 验证。

代入式 (4)

p_t(x) = p_0( φ^{-1}(x) ) · det[ ∂φ^{-1}(x)/∂x ]
逐项：

部件	计算
逆映射	φ^{-1}(x) = x/2
源点密度	p_0(x/2)：只要 x/2 ∈ [0,1]（即 0 ≤ x ≤ 2），它就等于 1
体积因子	一维取导数：d(x/2)/dx = 1/2
所以：


p_t(x) = 1 × 1/2 = 1/2,   0 ≤ x ≤ 2
       = 0,               其他
结果：[0, 2] 上的均匀分布，密度高度是 1/2。

数值核对
取 x = 1.5：


源点 = φ^{-1}(1.5) = 0.75
p_0(0.75) = 1
det = 1/2
p_t(1.5) = 1 × 1/2 = 1/2   ✓
再验总概率：


∫_0^2 (1/2) dx = 1   ✓
直观图

   p_0:  ████████              高 1，宽 1，面积 1
         [0──────1]
                │
                │  φ(x) = 2x  （拉长 2 倍）
                ▼
   p_t:  ████    ████          高 1/2，宽 2，面积仍是 1
         [0────────────2]
原来挤在 [0,1] 里的概率质量，现在摊到 [0,2] 上。质量不变、体积变 2 倍 ⇒ 密度减半，那个 1/2 就是式 (4) 里的 det。

更极端的简化：平移
若 φ(x) = x + 1，则 φ^{-1}(x) = x − 1，导数 = 1：


p_t(x) = p_0(x − 1) × 1 = p_0(x − 1)
分布只是被平移，密度形状与高度都不变——对应 det = 1（不拉伸体积）。

一句话
式 (4) 在这个例子里就是一句话：把 [0,1] 拉成 [0,2]，源点密度是 1，体积放大 2 倍，所以新密度是 1 × 1/2 = 1/2。
